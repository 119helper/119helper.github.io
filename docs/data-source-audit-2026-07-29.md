# API·정적 데이터 최신성 감사 — 2026-07-29

## 결론

- 2026-07-28 신청한 AED 위치 API와 K-water 댐 방류 API는 모두 실제 서비스 키로 정상 호출된다.
- 2026-07-29 소방청 다중이용업소 영업장별 API도 추가 신청 즉시 자동 승인됐고, 실제 키로 HTTP 200·154,873건을 확인했다.
- 구급통계는 단순한 최신자료 지연 외에 본부명 7개 지역과 응답 필드명이 실제 계약과 달라 정상 자료도 0으로 표시되던 앱 오류가 확인되어 교정했다.
- 공공 API 조회용 통합 시도명이 응급실 제목·주소까지 노출되던 문제를 발견해, 내부 공급자 명칭과 광주 5개 구 화면 표시명을 분리했다.
- 로컬 실키 스모크 테스트에서 주요 운영 API 경로가 모두 통과했다.
- 새 API 승인 없이 개선할 수 있는 자료는 공식 원문을 직접 내려받거나 현행 페이지와 대조해 갱신했다.
- 공개 원문 자체가 오래됐거나 최신 공표연도가 과거인 경우에는 값을 추정해 만들지 않고, 화면에 원자료 기준일과 확인일을 분리해 표시한다.

## 직접 갱신·교차검증한 자료

### 구급통계·구급정보

- [소방청 구급통계서비스](https://www.data.go.kr/data/15099428/openapi.do)의 원 API를
  2026-07-29 실제 키로 전수 조회했다.
- 2026-01~2026-07 월간 통계는 0건이고, 현재 최신 제공월은 2025-12다. 앱은 더 이상
  이 값을 고정하지 않고 현재 월부터 역순으로 원 API를 조회해 최신 제공월을 자동 감지한다.
- 2025-12 기준 앱 지원 17개 시·도 모두 정상코드와 1건 이상을 확인했다.
- 기존 매핑 중 부산·대구·광주·경기·강원·전북·제주 7개 지역의 본부명이 원 API의
  현재 값과 달랐다. 예를 들어 광주는 `광주소방안전본부`가 아니라 `광주소방본부`다.
- 통계 응답의 실제 건수 필드는 `gutCo`·`trnfCo`·`trnfPcnt`, 출동유형·연령·장소는
  `gutTyCdNm`·`ageScov`·`ruptOccrPlcCdNm`이므로 이 계약으로 집계하도록 교정했다.
- [소방청 구급정보서비스](https://www.data.go.kr/data/15099423/openapi.do)는 상세 기능에
  출동소방서가 필수이며, 구급활동정보만 `stmtYm`이 아니라 `gutYm`을 사용한다.
  지역 전체 조건으로 조용히 빈 결과를 내던 호출을 제거하고 화면에서 소방서를 선택하게 했다.
- 원 API가 제공하지 않는 현장 도착·귀소 소요시간을 계산하던 화면은 제거하고, 실제 제공
  필드인 출동시각·현장 이동거리·사고장소만 분석한다.
- 소방청이 2026-06-30 공개한
  [2026년 119구급서비스 통계연보](https://www.nfa.go.kr/nfa/releaseinformation/statisticalinformation/main/?pageIdx=1)는
  발간연도가 2026일 뿐 통계 기준일은 2025-12-31이다. 전국 출동 3,285,957건,
  이송 1,732,914건, 이송인원 1,747,940명과 2025 시도×월 표를 제공하며 원 API
  최신월 2025-12와 같은 자료연도다.
- 2026년 확정 시도·소방서 월별 구급통계는 현재 공개되지 않았다. 일일소방활동상황의
  전국 잠정 건수·인원은 최종 구급통계 계약과 의미·해상도가 달라 앱의 2026 지역자료로
  합치지 않는다.

- 광주: 원본 기준시점의 `광주광역시` 5개 구 경계로 3,873개소. API 요청에서는 `전남광주통합특별시`도 이 과거 기준 집계로 연결한다.

2026-07-29 새 자동변환 API 활용신청을 제출해 자동 승인됐고, 같은 서비스 키로 HTTP 200과
`totalCount=154873`을 확인했다. 앱은 주소·영업상태 조건으로 승인 API를 조회해 업종별로
집계하며, 외부 장애·키 누락·불완전 페이지가 발생하면 위 공식 CSV 검증값으로 자동
폴백한다. 기존 2019·2023·2024 API 경로는 과거 조회용으로 유지한다.

### 연간 화재통계·지역별 화재피해

- [공공데이터포털 연간화재통계](https://www.data.go.kr/data/15060386/fileData.do)의 건별 자동변환 자료는 2024년 37,614건까지다.
- 그러나 이 데이터셋만으로 “공식 최신연도”를 판정하면 안 된다. [소방청 주요통계](https://www.nfa.go.kr/nfa/releaseinformation/statisticalinformation/main/?pageIdx=1)에는 2025년도 화재통계연감이 공개됐고, [국가화재정보시스템(NFDS)](https://www.nfds.go.kr/stat/general.do)은 2026년 누계도 조회할 수 있다.
- 앱은 NFDS 검증 스냅샷을 우선 사용해 2025년 확정 38,344건과 2026-07-28까지 누계 24,260건을 제공한다. 2026년 값은 연간 확정값으로 표시하지 않는다.
- NFDS 공개 통계 화면의 시도 표를 월 단위로 조회해 2024·2025 전체 24개월과 2026년
  1~7월 누계의 화재·사망·부상·재산피해(천원)를 정적 스냅샷으로 보존한다. 각 월의
  시도 합계가 전국 월 총계와 일치해야 동기화가 성공한다.
- `지역별 화재피해` 화면은 최신 시도×월 집계와 2019~2023 개별 사고 자료를 탭으로
  분리한다. 최신 집계에는 공개되지 않은 주소·관할서를 만들어 넣지 않는다.
- 2026년 NFDS 전체 통계 24,260건 중 지역별 표에 분류된 값은 24,229건이다. 차이 31건은 특정 시도에 임의 배분하지 않고 `지역 미분류`로 보존한다.
- NFDS 재산피해 원자료 단위는 천원이다. 화면에서는 원화로 환산하고, CSV와 API 메타데이터에는 단위를 명시한다.
- [소방청 지역별 화재피해 현황](https://www.data.go.kr/data/15142972/openapi.do)의 공식 시간범위는 2019-01~2023-12다. 2024·2025 값을 0건으로 오인하거나 임의 생성하지 않고 화면에 제공범위를 표시한다.
- NFDS는 살아 있는 조회계라 발간 뒤 정정될 수 있다. 현재 NFDS 재산피해액은 2025
  화재통계연감 고정본과 139,368천원 차이가 있으므로 `collectedAt`을 함께 저장하고,
  고정 연감값과 현재 조회값을 섞지 않는다.

- [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법): 제15조·제18조

검증하지 못한 판례·사건 서술은 제거했다. 권한·보상·책임은 사실관계와 필요성·상당성에 따라 달라진다는 한계, 공식 원문 링크, 현행 여부 확인일을 각 카드에 넣었다.

## 공개 인터넷 원천 우선순위

기관 요청은 당장 보내지 않는다.

1. **NFDS 화재통계 — 공개 화면 스냅샷 자동화 완료**
   - 2024·2025 완결과 2026 누계를 매일 저빈도로 갱신하고 시도×월 합계를 검증한다.
2. **경북 위험물 — 2024·2025 도 합계 적용 완료**
   - 변경금지인 2024 통계연보 상세는 전재하지 않는다. 소방서별 화면은 재가공 가능한
     KOSIS 2023 값을 명시해 유지하고, 이후 허용 조건의 최신 공개본을 기다린다.
3. **지진해일 — 공개 API 647행 유지**
   - 680은 점검 대상 수이고 공개 680행 명부는 없다. 국민안전24와 대조해도 별칭·분할
     차이만 확인되므로 33행을 추정 생성하지 않는다.
4. **소방용수·공중화장실 — 라이선스와 좌표가 확인된 관할만 오버레이**
   - 광산구 2026 소방용수는 적용했다.
   - 공중화장실은 키 없는 [LOCALDATA 전국 CSV](https://www.data.go.kr/data/15075531/fileData.do)를
     기준 목록으로 전환하고 [서울 OA-22586](https://data.seoul.go.kr/dataList/OA-22586/S/1/datasetView.do),
     [제주시 15110521](https://www.data.go.kr/data/15110521/fileData.do),
     [부산 동래구 3079086](https://www.data.go.kr/data/3079086/fileData.do),
     [부산 갈맷길 15084238](https://www.data.go.kr/data/15084238/fileData.do)의 공식 좌표를
     중앙 관리번호에 결합했다.
   - 이름+도로명/지번주소가 고유하게 1:1 일치하고 관할 경계를 통과한 신규 990건만
     반영했다. 갈맷길 SHP 197건에서는 기존 좌표 32건을 제외하고 사상구 19건·수영구
     5건만 새로 보충했다. 원본 좌표 오류·공란, 이름만/주소만 일치, 중복 후보는 제외했다.
   - 대전 중구 2024 안심화장실 CSV와 울산도시공사 2025 CSV는 엄격 일치가 0건이었고,
     대구 공식 SHP는 행 갱신일이 2015~2016년이라 최신 자료로 가장하지 않고 제외했다.
