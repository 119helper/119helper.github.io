# API·정적 데이터 최신성 감사 — 2026-07-29

## 결론

- 2026-07-28 신청한 AED 위치 API와 K-water 댐 방류 API는 모두 실제 서비스 키로 정상 호출된다.
- 2026-07-29 소방청 다중이용업소 영업장별 API도 추가 신청 즉시 자동 승인됐고, 실제 키로 HTTP 200·154,873건을 확인했다.
- 로컬 실키 스모크 테스트에서 운영 API 23개 경로가 모두 통과했다.
- 새 API 승인 없이 개선할 수 있는 자료는 공식 원문을 직접 내려받거나 현행 페이지와 대조해 갱신했다.
- 공개 원문 자체가 오래됐거나 최신 공표연도가 과거인 경우에는 값을 추정해 만들지 않고, 화면에 원자료 기준일과 확인일을 분리해 표시한다.

댐 API의 0건은 장애가 아니라 조회 기간에 진행 중인 방류가 없다는 의미다. 응답 상태·형식·원문 XML까지 스모크 테스트에서 검사한다.

## 직접 갱신·교차검증한 자료

### 다중이용업소

- 공식 원문: [소방청_다중이용업소 영업장별 고유 일련번호_20250915](https://www.data.go.kr/data/15083979/fileData.do)
- 원본 다운로드·검증일: 2026-07-29
- CP949 CSV 실제 파싱: 154,873행
- 영업상태: 정상 113,235, 휴업 4,497, 폐업 37,098, 미분류 43
- 반영 방식: 영업상태가 `정상`인 행만 주소의 첫 시·도로 분류하고, 앱 지원 9개 지역을 업종별로 집계
- 앱 반영 합계: 48,736개소
- 광주: 원본 기준시점의 `광주광역시` 5개 구 경계로 3,873개소. API 요청에서는 `전남광주통합특별시`도 이 과거 기준 집계로 연결한다.

2026-07-29 새 자동변환 API 활용신청을 제출해 자동 승인됐고, 같은 서비스 키로 HTTP 200과
`totalCount=154873`을 확인했다. 앱은 주소·영업상태 조건으로 승인 API를 조회해 업종별로
집계하며, 외부 장애·키 누락·불완전 페이지가 발생하면 위 공식 CSV 검증값으로 자동
폴백한다. 기존 2019·2023·2024 API 경로는 과거 조회용으로 유지한다.

### 연간 화재통계·지역별 화재피해

- [소방청 연간화재통계](https://www.data.go.kr/tcs/dss/selectFileDataDetailView.do?publicDataPk=15060386)의 최신 공개 자료는 2024년 37,614건이며, 포털의 차기 등록 예정일은 2026-11-18이다. 앱의 최신 선택연도 2024는 현재 올바르다.
- [소방청 지역별 화재피해 현황](https://www.data.go.kr/data/15142972/openapi.do)의 공식 시간범위는 2019-01~2023-12다. 2024·2025 값을 0건으로 오인하거나 임의 생성하지 않고 화면에 제공범위를 표시한다.

### 위험물 제조소 통계

- 공식 원문: [KOSIS 위험물제조소 설치현황](https://kosis.kr/statHtml/statHtml.do?orgId=216&tblId=DT_21603_P001027&conn_path=I3)
- 2026-07-29 현재 표의 공표 범위는 2011~2023이고, 최신 공표연도는 2023이다.
- 2023년 합계 9,546개소와 소방서별 값을 유지하고, `데이터 갱신일` 대신 `공식 최신 여부 확인일`을 표시한다.

### 응급처치 참고자료

- 소방청이 공개한 최신 `119구급대원 현장응급처치 표준지침`은 [2023년 개정본](https://www.nfa.go.kr/nfa/publicrelations/legalinformation/archives/?cntId=50&mode=view)이다.
- 대한심폐소생협회는 별도로 [2025년 한국 심폐소생술 가이드라인](https://www.kacpr.org/download/2025%EB%85%84%20%ED%95%9C%EA%B5%AD%20%EC%8B%AC%ED%8F%90%EC%86%8C%EC%83%9D%EC%88%A0%20%EA%B0%80%EC%9D%B4%EB%93%9C%EB%9D%BC%EC%9D%B8.pdf)을 공개했다.
- 전 항목이 KACPR 자료인 것처럼 보이던 출처 표기를 분리했다. 임상 값은 검증 없이 섞어 바꾸지 않고, 최신 기관 지침과 의료지도를 우선하도록 표시한다.

## 법령 자료 교정

기존 법률방어 카드에는 존재하지 않는 사건 사례, 잘못된 조문, `100% 면책` 같은 단정이 섞여 있었다. 다음 현행 법령 원문으로 전면 교체했다.

- [소방기본법](https://www.law.go.kr/법령/소방기본법): 제16조의5·제16조의6·제25조·제49조의2
- [119구조ㆍ구급에 관한 법률](https://www.law.go.kr/법령/119구조ㆍ구급에관한법률): 제10조·제10조의2·제13조·제15조·제22조·제28조
- [도로교통법](https://www.law.go.kr/법령/도로교통법): 제29조·제30조
- [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법): 제15조·제18조
- [형법](https://www.law.go.kr/법령/형법): 제21조

검증하지 못한 판례·사건 서술은 제거했다. 권한·보상·책임은 사실관계와 필요성·상당성에 따라 달라진다는 한계, 공식 원문 링크, 현행 여부 확인일을 각 카드에 넣었다.

## 추가 API 신청 우선순위

1. **소방청 다중이용업소 영업장별 고유 일련번호 API(15083979) — 신청·연동 완료**
   - 2025 개별 영업장 15만여 행으로 자동 연간 갱신과 업소 단위 검색이 가능하다.
   - 2026-07-29 활용신청 즉시 자동 승인됐고 실제 키 호출도 정상이다.
   - 승인 API 실시간 집계를 우선 사용하고, 이번 공식 CSV 집계를 장애 안전망으로 유지한다.
2. **KOSIS 공유서비스 — 신청 가치 낮음**
   - 위험물 통계는 연 1회이고 공식 최신연도가 아직 2023이라 수동 확인 비용이 작다.
   - 새 연도가 공표될 때 자동 감지하는 용도 외에는 당장 사용자 가치가 제한적이다.
3. **소방용수·지진해일 대체 API — 추가 신청 보류**
   - 소방용수는 공급원 자체가 2024년 자료이고, 지진해일은 행별 갱신일이 없다. 다른 키를 추가해도 최신성 문제가 해결되지 않는다.

당장 추가 신청할 가치가 큰 API는 모두 처리했다. KOSIS와 소방용수·지진해일 관련 API는
신청 수를 늘려도 원자료 공표주기나 기준일 문제가 해결되지 않아 보류한다.
