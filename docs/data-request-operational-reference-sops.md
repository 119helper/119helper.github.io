# 현장 참고자료 공식 판본·SOP 요청 초안

> 상태: **발송 보류**. 공개된 최신 기관 원문과 판본을 우선 대조하고, 미확인 항목은
> 화면에서 공식 SOP가 아닌 참고자료로 제한한다.

## 목적

시설·통계 데이터와 별개로 ERG, 중증도 분류, 장비 점검, 심신건강 문항은 판본과 기관
적용 규칙이 확인돼야 한다. 공식 대조 전에는 교육용 참고로만 표시한다.

## 요청 항목

### 유해화학물질 ERG

- PHMSA ERG 2024의 UN 번호별 소량·대량, 주간·야간 초기이격·방호거리
- 한국 기관에서 사용하는 번역판·개정판과 사용허락
- 원문 표의 행 식별자, 단위, 특수표시(P) 의미

수령 후 30종 전 항목을 판본·조건별로 대조하고, 현재처럼 하나의 방호거리만 표현하는
구조가 원표를 훼손하면 계산 기능을 개편하거나 비활성화한다.

### START / JumpSTART

- 국내 재난현장 중증도분류 성인·소아 알고리즘
- 적용 연령 경계, 검정 태그 정의, 재분류 주기, 시행일·개정이력
- 현장 의료지도와 수용병원 연계 시 우선순위 규칙

미국 HHS 공개 알고리즘과 유사하다는 이유만으로 국내 SOP 승인을 대신하지 않는다.

### 개인보호장비 점검

- 최신 개인보호장비 점검부와 장비별 필수 점검 항목
- 공기호흡기 모델·용기 사양별 충전압력과 저압경보기 기준
- 제조사 매뉴얼과 기관 점검표가 다를 때의 우선순위

단일 `250bar 이상` 기준은 제거했으며, 공식 장비·기관별 기준을 수령한 뒤 조건형 규칙으로
반영한다.

### 심신건강

- 소방공무원 대상 승인 선별도구, 사용허락, 문항, 채점법, 절단점
- 위기응답 절차와 권역별 마음건강센터 최신 연결표
- 상담전화·기관명·운영시간의 확인 기준일

현재 6문항은 상태 기록용이며 검증된 절단점이 없어 `양호/주의/상담 권장` 자동 판정을
제거했다.
