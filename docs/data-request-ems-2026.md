# 2026 구급통계 제공 일정 확인 요청 초안

> 상태: **발송 보류**. 2025 확정 자료는 2026년 119구급서비스 통계연보와 원 API
> 2025-12 자료로 확인했다. 2026 시도·소방서 확정 자료는 공개본을 기다린다.

## 배경

2026-07-29 실호출 기준 `소방청 구급통계서비스`의 2026-01~2026-07 월간 응답은 0건이고,
최신 제공월은 2025-12다. 앱은 현재 월부터 역순으로 조회해 최신 제공월을 자동 감지한다.

## 문의 본문

제목:

> 소방청 구급통계서비스 2026년 월간 자료 개방 일정 및 0건 의미 확인

본문:

> `소방청 구급통계서비스`에서 2026년 1월 이후 조회가 정상 응답이지만 0건으로
> 반환됩니다. 2026년 자료의 최초 공개 예정월, 월별 갱신 주기, 잠정치·확정치 구분,
> 0건 응답이 미집계인지 실제 0건인지 확인을 요청합니다.
>
> 가능하다면 2026년 시도별 월간 구급출동·이송·환자 통계와 데이터기준일,
> 최종수정일을 기존 API 계약으로 제공해 주십시오. 본부명이나 코드가 변경되는 경우
> 변경표도 함께 요청드립니다.

## 수용 기준

- 정상 0건과 미제공을 구분할 상태 또는 메타데이터가 있어야 한다.
- 월별 제공 종료월과 확정 여부를 표시할 수 있어야 한다.
- 17개 시도 합계와 전국 합계를 대조할 수 있어야 한다.
